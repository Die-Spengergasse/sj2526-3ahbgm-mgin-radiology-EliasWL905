# Radiology Reservation System


## Start the SpringThymeleafApplication:

Now you can access it over your browser over `http://localhost:8080`



### 1. Register a Patient
Before booking an appointment, a patient must be registered in the database.
* Navigate to the **"Add Patient"** page.
* Enter the information.
* Save your changes.

### 2. Create a Reservation
Once a patient is in the system, you can assign them to a machine and a time slot.
* Navigate to the **"Add Reservation"** page.
* Enter the information.
* Add an optional **Comment** and save your changes.

### 3. View the Schedule
To see the availability or appointments for a specific machine:
* Navigate to the **"Devices"** page.
* Select a device to display all scheduled appointments in a table.
